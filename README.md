## **About the Project**
This is a simple HTML/CSS-based portfolio website that serves as a platform to display my projects, share a bit about myself, and provide ways to connect with me online. The site is designed to be clean, responsive, and easy to navigate

## **Features**
- Home Page: A brief introduction and welcome message.
- About Page: Learn more about my background and interests.
- Work Page: View my projects, with links to live demos and GitHub repositories.
- Connect Page: Contact information and a simple form to send me a message.
- Social Media Links: Easily connect with me on various platforms.

## **Technologies Uses**
- HTML5: For the structure and content of the website.
- CSS3: For styling and layout.
- JavaScript: For any interactivity and enhancements.
- Normalize.css: To ensure consistent styling across browsers.
- Google Fonts: For custom typography.
- tota11y: For accessibility auditing.

### **Accessibilty**
This portfolio incorporates tota11y, a tool that helps in identifying and addressing accessibility issues. The script is included to ensure the website meets accessibility standards, making it usable for a wider range of people, including those with disabilities.

- tota11y: This script can be activated by opening the `index.html` in a browser. It adds a toolbar that allows you to inspect the site for various accessibility issues.
